# Explore your workspace

## Write

Use Editor for visual writing, Source for Markdown, or Split to compare them. Expand Tools when you need formatting or media controls.

## Connect

Link to [[Writing/Field journal]] and [[Research/Glossary]]. Open Context to inspect linked files and backlinks.

## Organize

Use folders for reference material and Projects for a focused body of work. Try [[Projects/Lantern Trail/Project brief]].

## Review

Make a small edit, save it, and use Revisions to compare versions. Server confirmation matters more than a decorative success message.

## Explore media

Open an image's options, experiment with text flow, and add project gallery tags. Listen to [[Audio/Sound sketch]].
