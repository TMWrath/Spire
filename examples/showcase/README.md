# Spire showcase collection

Fictional, original demonstration content for Spire. The Markdown, PNG illustrations, and synthesized audio in this directory are dedicated to the public domain under CC0-1.0. No personal information, external media dependencies, or private server addresses are included.

## Import

Use Spire’s folder import workflow to import the **contents of `vault/`**, retaining their relative folder paths. If that workflow is unavailable on your client, use its supported file/folder import controls; never replace an existing data directory or `state.json`. Keep attachments with the documents that reference them. Do not import this README as a loose root document.

Start with `Welcome/Start here.md`. The fictional project lives at `Projects/Lantern Trail/`. Project image tags use the same `spire_image_tags` frontmatter as the gallery. Task checkboxes are examples; they do not pre-create task-board records.

All images and audio are included locally. Changes to these examples are safe to experiment with. Import into an empty workspace or check for path collisions first; do not overwrite your own files.
